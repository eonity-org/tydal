# Brand SVGs

Vector versions of the TYDAL logo and the "ty" isotype, kept for uses where
vectors fit: large sizes, print, presentations, documentation. They aren't
imported anywhere yet.

The app header and login page use `../tydal-logo.png` on purpose: at 48–70 px
the logo's thin connecting line renders with artifacts in Chrome as an SVG,
while the PNG, exported at pixel size, stays clean.

- `tydal-logo.svg` (colour), `tydal-logo-monochrome.svg` (#0A5475), `tydal-logo-white.svg`
- `ty-isotype.svg` (tight), `ty-isotype-square.svg` (square, the master's framing)
